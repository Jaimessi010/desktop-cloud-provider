
# Lista de verificación para releases

## 1. Control de versiones
- [ ] Identificar la rama y el commit.
- [ ] Revisar las modificaciones realizadas.
- [ ] Verificar el estado del Pull Request.

## 2. Compilación y pruebas
- [ ] Ejecutar `make build`.
- [ ] Ejecutar `make test`.
- [ ] Comprobar los resultados de GitHub Actions.

## 3. Preparación de artefactos
- [ ] Verificar el ejecutable generado.
- [ ] Comprobar la imagen Docker.
- [ ] Identificar la versión del artefacto.

## 4. Documentación
- [ ] Actualizar la documentación del proyecto.
- [ ] Registrar los resultados obtenidos.
- [ ] Documentar errores y limitaciones.

## 5. Liberación
- [ ] Confirmar las validaciones exitosas.
- [ ] Verificar el destino de publicación.
- [ ] Autorizar la liberación.
